## Project Description

**zk-lastwill** is a decentralized “proof-of-life” protocol that allows a person to program the distribution of their digital assets while preserving privacy.

---

## Tech Stack

- Solidity (smart contracts)
- Zero-Knowledge Proof system (circom/snarkjs or mock verifier for MVP)
- ERC-20/ERC-721/ERC-1155 for asset distribution
- RWA token standard: ERC-3643 / ERC-1400

---

## Objectives

By the end of **ARG25**, the goal is to have:

A minimal frontend dashboard:

- Owner view: “Send heartbeat” button, expiration timer, beneficiary list
- Beneficiary view: inheritance status, readiness to receive funds, and claim

Simple demo deployment to a testnet (e.g., Polygon, Base, or Sepolia)

RWA mock token + forced transfer to heirs
